# API contract

Base path: `/api`. OpenAPI is generated by FastAPI in non-restricted environments.

## Conventions

- JSON request/response bodies; validation failures use HTTP 422.
- Authenticated APIs accept `Authorization: Bearer <short-lived-token>`.
- Refresh/logout use HttpOnly refresh cookie plus `X-CSRF-Token`.
- Mutating checkout/payment/shipment operations use idempotency keys or provider event IDs.
- Errors return a safe `detail` and production envelope containing `error.code`, `error.message` and `request_id`.
- Prices, discounts, tax, delivery and inventory returned by quote/order APIs are authoritative.

## Critical flow

1. `POST /checkout/quote` with product/variant IDs, quantity, destination and optional coupon.
2. `POST /orders` with the same canonical identifiers, shipping address and `Idempotency-Key`.
3. COD confirms immediately; online checkout calls `POST /payments/create-order`.
4. Browser payment verification is provisional; `POST /payments/webhook` is authoritative and signed.
5. Admin shipment creation uses the shipping adapter; `POST /shipping/webhook` is signed and idempotent.

Important groups include `/auth`, `/catalog`, `/products`, `/addresses`, `/orders`, `/payments`, `/shipping`, `/return-requests`, `/reviews`, `/coupons`, `/admin`, `/privacy`, `/health`, `/ready` and `/metrics`. See `API_DOCUMENTATION.md` and generated OpenAPI for field-level schemas.
